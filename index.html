Privacy Policy for GitHub PR Helper

Last Updated: December 2024

Introduction

GitHub PR Helper ("we", "our", or "the extension") is committed to protecting your privacy. This Privacy Policy explains how we handle information when you use our Chrome extension.

Data Collection

We do not collect, store, or transmit any personal data or user information.

The extension operates entirely locally on your device and only enhances GitHub pull request pages with additional features.

What We Do

Local Storage

The extension uses Chrome's local storage API to:

  • Store extension settings - Save your preferences such as file size warning threshold, template checker, quick actions, tree view, and quick search
  • Store domain preferences - Remember which domains have the extension enabled or disabled
  • Store viewed files - Track which files you've marked as viewed for your own reference (only file paths, not content)

All data is stored locally on your device and is never transmitted to any third-party servers or services.

GitHub Page Enhancement

The extension enhances GitHub pages (pull requests, repositories, and file trees) when you visit them by:

  • Calculating and displaying PR statistics (lines added/removed, files changed)
  • Adding file size warnings for large files
  • Adding quick action buttons (approve, request changes, comment)
  • Checking if PR follows the template
  • Displaying a file tree view for easy navigation
  • Enabling quick file search (Ctrl+I / Cmd+I)
  • Allowing commit switching via keyboard shortcuts
  • Tracking which files you've viewed (marked as reviewed)

The extension:

  • Only reads page content from the DOM (file lists, PR statistics, file paths)
  • Only modifies the appearance and adds functionality to GitHub pages
  • Stores your viewing preferences locally (which files you've marked as viewed)
  • Stores your domain preferences (which domains have the extension enabled)
  • Does not access or store any PR content, code, or descriptions
  • Does not access any personal information or sensitive data
  • Does not read or store any GitHub user data
  • All enhancements are applied locally in your browser
  • Statistics are calculated from the page content, not stored
  • File tree structure is built from the page DOM, not stored

Permissions Explained

storage

Used to save your extension settings locally on your device. All data remains on your device and is never transmitted.

Host Permissions

  • https://github.com/* - To enhance GitHub pages (pull requests, repositories, file trees) with additional features
  • https://*.github.com/* - To support GitHub Enterprise and private GitHub instances
  • https://api.github.com/* - Optional: To fetch additional PR data from GitHub's public API (if implemented in future versions)

These permissions are only used to apply enhancements to GitHub pages. No data is collected or transmitted. If the extension uses GitHub's API in the future, it will only access publicly available information and will not require authentication.

Data Sharing

We do not share, sell, or transfer any data to third parties.

All data remains on your device. We do not:

  • Collect personal information
  • Track user behavior
  • Share data with advertisers
  • Sell data to third parties
  • Use data for any purpose other than enhancing GitHub PRs
  • Access or store GitHub PR content
  • Transmit any data to external servers

Third-Party Services

The extension does not communicate with any external servers or third-party services. All functionality operates entirely locally on your device. If the extension uses GitHub's public API in the future, it will only access publicly available information and will not transmit any data.

Your Rights

Since we do not collect any personal data, there is no personal data to access, modify, or delete. All stored settings and preferences can be cleared by:

  • Resetting settings in the extension popup
  • Disabling the extension for specific domains
  • Clearing your viewed files list
  • Uninstalling the extension
  • Clearing Chrome's extension storage
  • Disabling the extension

All data stored locally (settings, domain preferences, viewed files) can be cleared at any time through the extension settings or by uninstalling the extension.

Children's Privacy

Our extension does not knowingly collect any information from children. Since we do not collect any data, this is not applicable.

Changes to This Privacy Policy
